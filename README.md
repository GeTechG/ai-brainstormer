# brainstormer

Репозиторий-маркетплейс с плагином **`ai-brainstorm`** для Claude Code —
многоагентный кросс-модельный инструментарий. В плагине **два скилла**:

- **`ai-brainstorm`** — мозговой штурм. Один **ведущий** (lead) пишет ответ, один
  или несколько **судей** (judges) состязательно его ревьюят раунд за раундом,
  пока не кончатся аргументы. На выходе — единый, закалённый критикой план.
- **`ai-review`** — кросс-модельное ревью кода. **Судья** другой модели (Claude →
  Codex по умолчанию, или наоборот) в чистой сессии ревьюит твои незакоммиченные
  изменения, а ты — **ответчик**, запустивший скилл, — чинишь или аргументированно
  оспариваешь каждое замечание раунд за раундом, пока судья не скажет «чисто».

## Что внутри

```
brainstormer/                          ← маркетплейс Claude Code (корень репо)
├── .claude-plugin/
│   └── marketplace.json               ← манифест маркетплейса
├── plugins/
│   └── ai-brainstorm/
│       ├── .claude-plugin/
│       │   └── plugin.json            ← манифест плагина
│       └── skills/
│           ├── ai-brainstorm/
│           │   ├── SKILL.md           ← рабочий процесс оркестратора штурма
│           │   ├── scripts/
│           │   │   └── run_round.py   ← параллельный запуск CLI, сессии, таймауты
│           │   └── references/
│           │       └── prompt-templates.md
│           └── ai-review/
│               ├── SKILL.md           ← рабочий процесс ответчика (использует тот же run_round.py)
│               └── references/
│                   └── review-prompts.md
└── README.md
```

> `ai-review` переиспользует `run_round.py` из скилла `ai-brainstorm` — отдельной
> копии раннера нет.

## Архитектура: кто где

- **Скиллы `ai-brainstorm` и `ai-review` — это скиллы Claude Code.** Они живут
  внутри Claude Code и управляют процессом.
- **`claude` и `codex` — участники.** Скилл запускает их как отдельные headless
  CLI-сессии (`claude -p`, `codex exec`). Их **не нужно** никуда «устанавливать»
  как плагин — нужно лишь, чтобы оба CLI были установлены и залогинены в системе.
- **Разница ролей.** В `ai-brainstorm` живая сессия — нейтральный оркестратор, а
  lead и судьи headless и read-only. В `ai-review` наоборот: живая сессия — это
  **ответчик**, который сам правит код и крутит цикл, а headless **судья** другой
  модели остаётся read-only и каждый раунд перечитывает живое дерево.

## Установка

### 1. Плагин в Claude Code

Из локального пути:

```
/plugin marketplace add /home/sergey/brainstormer
/plugin install ai-brainstorm@brainstormer
```

Либо, если запушишь репозиторий на git-хостинг:

```
/plugin marketplace add <git-url-репозитория>
/plugin install ai-brainstorm@brainstormer
```

Обновление после изменений в репозитории:

```
/plugin marketplace update brainstormer
```

### 2. Codex как участник

`codex` CLI должен быть установлен и аутентифицирован:

```
codex --version      # проверка наличия
codex login          # вход, если не залогинен
```

Скилл сам делает preflight-проверку обеих CLI перед запуском штурма
(`python3 .../scripts/run_round.py --check`).

## Использование

В любом проекте внутри Claude Code попроси штурм, например:

> «проведи мозговой штурм: <тема>»
> «пусть claude и codex независимо обдумают X, а потом сведут к общему плану»

Оркестратор спросит тему и роли (по умолчанию `claude` — ведущий,
`codex` — судья), прогонит раунды и положит результат в
`brainstorms/<slug>/final-plan.md` внутри текущего проекта.

### Кросс-модельное ревью (`ai-review`)

Внеси изменения в проект (можно не коммитить) и попроси ревью, например:

> «пусть codex отревьюит мои изменения»
> «прогони кросс-модельное ревью незакоммиченных правок и крути, пока не будет чисто»
> «пусть другая модель отревьюит этот PR / ветку»

Область ревью — на выбор: незакоммиченные изменения (по умолчанию) или **целый
PR/ветка** (всё, что ветка привносит относительно базы, через merge-base-дифф
`git diff base...HEAD`; для GitHub-PR — сначала `gh pr checkout`). Скилл сделает
preflight судьи, запустит судью другой модели в чистой сессии и будет крутить
цикл: судья находит замечания → ты чинишь (в ветке — фикс-коммитами) или
оспариваешь → судья перепроверяет в той же сессии — пока не останется
блокеров/важных замечаний. Результат — `reviews/<slug>/review-summary.md`.

## Замечания

- Папки `brainstorms/` и `reviews/` создаются в том проекте, где идёт работа —
  это рантайм-вывод, в этот репозиторий они не входят (см. `.gitignore`).
- Если раньше скилл стоял как персональный (`~/.claude/skills/ai-brainstorm/`),
  после установки плагина персональную копию лучше удалить, чтобы скилл не
  задваивался.

## Требования

- Claude Code CLI
- Codex CLI (`codex`), залогинен
- Python 3 (только стандартная библиотека — внешних зависимостей нет)
